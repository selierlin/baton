功能介绍

每个模块做什么、键位怎么按，哪儿还不行

这一页写给准备长期用它的人：比首页细，比源码短。所有快捷键都是默认值，可以在设置里改。

01 · 截图

三种框选，一套标注

区域、窗口、元素都从同一个入口进：⌥⌘A。鼠标停在窗口或元素上会先框出来，单击即选；直接拖就是自由框选。

框选的时候就能读屏

光标旁跟着一个放大镜（一格 = 屏幕 1pt，放大 9 倍），底部三行实时报坐标、选区尺寸和色值。

  • 按 C 直接复制光标所在像素的颜色
  • T 切换色值格式：hex → rgb → hsl
  • 方向键微调 1pt，⌘ 扩、⇧ 收，F 直接选整屏

标注是接着截图做的

圈完直接落在标注画布上，不经过「存文件 → 打开 → 导入」。

  • 方框、椭圆、箭头、画笔、记号笔、马赛克（块 / 笔两种）、高亮、文字、序号、尺规
  • 颜色、线宽、字号都在工具条上，画完还能改
  • ⌘Z / ⇧⌘Z 撤销重做，⌘C 复制、⌘D 保存
  • 圈小了不用重截：选区四周的把手可以拖，已经画的图元贴着画面内容不动

02 · 贴图

截图钉在屏幕上，当参考用

对着图抄代码、比设计稿、把一段报错留在视线里。⌥⌘P 把当前选区贴出来，也可以把文件拖进已有的贴图再贴一张。

缩放、收起来、再放回来

  • 滚轮或触控板双指滑动缩放，围着你指的那一点长大缩小
  • 手动调过的尺寸会被记住：按 R 收成缩略图，再按 R 回到刚调好的大小，而不是原图大小
  • 缩略图带一圈加粗边框，一眼分得出「收起来的」和「本来就这么小的」
  • 双击在 100% 和「适配屏幕」之间切
  • ⌃⌘7 一键把所有贴图藏起来，再按一次回来，位置不变

贴图上还能接着干活

  • 点一下贴图，再按 空格 就进标注；标完选「贴图」把结果再钉一张，两张并排对比
  • ⌘- / ⌘= 调不透明度，垫在下面当底图时很好用

  • 右键菜单里还有 50% / 100% / 200% 预设、保存到本地、只复制不保存

03 · 取字与翻译

看得见，就能取出来

截图 OCR ⇧⌘O，截图翻译 ⇧⌘Y，划词翻译 ⇧⌘T。

识别引擎

  • 本机 Vision：默认引擎，免费、离线、快，中英混排够用
  • 百度 / 腾讯：自己填 App ID 和密钥，换成云端识别；腾讯走 TC3 签名，和翻译共用一套配置
  • 结果按行排好，可以直接复制；图里有二维码会一起解出来

翻译引擎

  • OpenAI 兼容接口：DeepSeek、OpenAI、Kimi、智谱、硅基流动，本地 Ollama 也行
  • 百度翻译、腾讯翻译，只需填账号和密钥
  • 「测试连接」当场发一句 hello 走真链路，配置对不对立刻知道
  • 划词翻译取词分两步：先问系统的选中文本，拿不到再走 WebKit 的文本标记
04 · 其他

常驻在菜单栏里的小工具

剪贴板历史 ⇧⌘V

文字 / 图片 / 文件 / 颜色分类筛选，↑↓ 选、↩ 粘到前台 App、⌥↩ 只粘纯文本。粘贴栈：⇧↑↓ 框多条，之后每按一次 ⌘V 自动换下一条。

输入法记忆

按 App 记住；可以给浏览器地址栏单独指定英文源；网站规则支持「整站」和「指定输入框」两级；同一个框连续两次手动换源会自动学成规则。

平滑滚动

把鼠标滚轮的离散事件插值成 120Hz 的运动，接近触控板手感。拦截失败或滚动手感不合适，菜单里一键关。

长截图 ⌥⌘L

边滚边拼，自动对齐。单帧位移过大（甩太快）会在成图上标黄底断点，宁可标出来也不给错位的图。

屏幕尺子 ⌥⌘R

拖一条线量像素，带吸附；顺手取色。校对间距、还原设计稿时少开一个工具。

录屏 ⌃⌘8

区域 / 整屏 / 窗口 / 应用四种模式。系统声音和麦克风旁白混成一轨，成片是普通 MP4，落在 ~/Movies/Baton。

快捷键

19 个动作都能改，行尾 ✕ 取消绑定、↺ 恢复默认；和系统键撞了会提示。整份配置可以导出导入。

菜单与设置

菜单按「截图 / 录制 / 贴图 / 文字」分组，最常用的区域截图留在外面；设置用工具栏切页，每页只放一类的开关。

出问题能查

每个动作都写一行日志到 ~/Library/Logs/Baton/baton.log，设置 → 关于 里一键打开，遇到问题把这一个文件发出来就能复盘。

边界

这些地方现在还不行

写出来比让你踩坑强。

没有 Apple 公证，也没有自动更新

首次打开要右键 → 打开；新版本需要自己回来下载。以后可能会加 Sparkle，现在没有。

发布构建只有 Apple 芯片

Intel 机器需要自己编译，未做验证。最低系统是 macOS 15，老系统不支持。

插件式扩展、脚本化都没有

没有 URL scheme、没有 AppleScript 字典、没有插件系统。快捷键和菜单是唯一的入口。

云服务要自备密钥

百度、腾讯、各家大模型的账号和额度都得自己开。Baton 不代付、不代理，也不做用量统计。

网站输入法规则只能靠无障碍文案

拿不到 DOM 选择器，所以同文案的多个输入框分不开；富文本编辑器常常不暴露文案，只能落到整站规则。
