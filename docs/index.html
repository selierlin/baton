功能

四件事做到了，日常就顺了

截图之后的每一步都不用换工具：标注、贴图、取字、翻译，全在同一个窗口链里。

从框选到标注，中间不落地

拖一下就是区域截图，鼠标停在窗口或元素上会先框出来，单击即选。圈完直接进标注，不用先存文件再打开。

  • 放大镜跟着光标，实时报坐标、选区尺寸和像素色值
  • 方框、椭圆、箭头、画笔、马赛克、高亮、文字、序号、尺规，画错了 ⌘Z
  • 圈完发现多截了一块？选区四周的把手还能拖，已经画的图元贴着画面不动

想要的图，钉在屏幕上

截图直接变成一块浮在窗口上方的贴图，对着它抄代码、比对设计稿都行。多张并存，点哪张键盘就归哪张。

  • 滚轮和触控板双指滑动缩放，围着你指的地方长大缩小

  • 贴图上还能继续标注，标完「再贴一张」把结果钉在旁边
  • 贴图有记忆：关掉 App 再打开，位置和大小都还在

图里的字，取出来就能用

框完按 ⇧⌘O 取字，按 ⇧⌘Y 连取带翻。本机 Vision 引擎免费离线，也能接百度、腾讯；翻译可以走 DeepSeek、Kimi、Ollama 这类 OpenAI 兼容接口。

  • 识别结果按行排好，带二维码的图会顺手把码解出来
  • 划词翻译不用截图：选中一段文字按 ⇧⌘T，浮窗贴在鼠标旁边
  • 服务和密钥都在设置里，两页都有「测试连接」，配完当场验一遍

还有

顺手补上的那些小工具

不是功能清单堆料，是每天真的会用到的几个开关。

剪贴板历史

文字、图片、文件、颜色都能翻回来。支持粘贴栈、侧滑预览，图里的字也能搜到；密码类内容一律不落库。

输入法记忆

按 App 记住输入法，切回来自动恢复。浏览器地址栏切英文、按网站甚至按输入框指定，写代码不再第一下打出中文。

平滑滚动

给普通滚轮加一层 120 Hz 的惯性重放，长网页翻起来不那么顿。随时在菜单里关掉。

长截图

边滚边拼，超速或页面乱动的地方会标出断点，而不是给你一张错位的图。

屏幕尺子

量像素、取色值，带吸附。对设计稿和前端还原特别顺。

录屏

区域、整屏、单窗口、单应用四种模式，带系统声音和麦克风旁白，成片是普通 MP4。

快捷键全部可改

19 个动作都能重设或取消绑定，撞了系统键会提示；配置可以导出导入，换机器一键搬家。

本地优先

没有账号，没有遥测。剪贴板库、贴图、配置都躺在自己的 Application Support 目录里。

隐私

你的数据，不上我的服务器

Baton 没有后端。除了你自己在设置里填的云服务地址，它不往外发任何东西。

没有账号下载即用，不需要注册，也没有遥测埋点。
本地存储剪贴板库、贴图、配置都在 ~/Library/Application Support/Baton。
离线 OCR默认用系统 Vision，识别过程完全在本机。
机密不落库密码管理器标记为机密或临时的剪贴板内容，一条都不存。
常见问题

动手之前可能会问

为什么系统提示「无法验证开发者」？

因为发布的是自签名构建，没有走 Apple 公证（个人项目，年费不值）。右键 → 打开 就能放行，系统会记住这一次选择。介意的话可以自己 clone 下来编译，签名用你自己的开发证书。

需要给哪些权限？

屏幕录制用于截图和录屏，辅助功能用于元素截图与划词，输入监控用于平滑滚动。三个都可以拒绝，拒了只是对应功能不可用，剪贴板、贴图这些照常工作。

OCR 和翻译会把内容传到网上吗？

默认不会：OCR 走本机 Vision。只有你自己在设置里配了百度、腾讯或某个大模型接口，那一部分内容才会发给你配的服务商，密钥存在系统钥匙串里。

支持 Intel 和 macOS 14？

代码本身没有绑定 Apple 芯片，但发布的构建是 arm64 的，最低系统写的是 macOS 15（用到了 ScreenCaptureKit 的新接口）。Intel 和更老的系统需要自己编译，能否跑通没有验证过。

和系统截图、CleanShot 那些比呢？

Baton 的起点是「我不想同时开五个 App」。截图标注只是其中一块，贴图、取字翻译、剪贴板、输入法记忆都在同一个菜单里，样式和键位尽量贴着 macOS 的原生习惯走。

会开源吗？可以提需求吗？

源码已经在 GitHub 上，MIT 许可。issue 和 PR 都欢迎，但这是个人项目，不保证响应时间。
